# Conversation plan format

Use the sections that help execution. This file is a skill reference; deliver the completed plan in the conversation.

## Objective and acceptance

Expected outcome, observable criteria and exclusions.

## Confirmed context

Necessary decisions, constraints and evidence. Distinguish facts from hypotheses.

## Steps

**P1 — concrete outcome**

- Targets: files and symbols.
- Depends on: actual prerequisites.
- Action: intent of the change.
- Constraints: specific boundaries.
- Proof: command/action → expected result.

Repeat only for necessary steps.

## Final verification

Acceptance criterion → case/command that demonstrates it.
Include affected consumers and the main flow.

## Risks and open items

Questions that block execution, unavailable checks and rollback where material.
